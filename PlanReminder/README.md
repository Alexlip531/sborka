# PlanReminder — Android-приложение «Планы и напоминания»

Android-приложение для планирования дел с напоминаниями через push-уведомления.

## Возможности

- **Список планов** с вкладками «Все / Активные / Выполнено»
- **Добавление плана**: название, описание, дата, время, цвет метки
- **Напоминания** через системные уведомления в заданное время
- **Действия из уведомления**: «Отметить выполненным» и «Отложить на 15 мин»
- **Автоперезапуск** напоминаний после перезагрузки телефона
- **Тёмная тема** (по системной настройке)
- **Адаптивный Material 3 дизайн**

## Скриншоты возможностей

- Главный экран: список карточек с цветными метками, статусом (через 2 ч / просрочено), кнопками «выполнить» и «редактировать»
- Экран редактирования: поля названия и описания, карточки выбора даты/времени, выбор цвета
- Уведомление с двумя кнопками действий

## Технические характеристики

- **Минимальный Android**: 7.0 (API 24)
- **Целевой Android**: 14 (API 34)
- **Язык**: Kotlin
- **Архитектура**: Single-activity + Room + AlarmManager
- **Библиотеки**:
  - AndroidX Core, AppCompat, Material 3
  - Room (база данных)
  - Coroutines (асинхронные операции)
  - ViewBinding

## Установка

1. Скопируйте `PlanReminder-1.0.apk` на телефон
2. Откройте файловый менеджер и тапните по файлу
3. Разрешите установку из неизвестных источников (один раз)
4. Нажмите «Установить»

После установки:
- При первом запуске **разрешите уведомления** (появится диалог)
- На Android 12+ может потребоваться разрешение на точные будильники: Настройки → Приложения → Планы и напоминания → Будильники и напоминания → Разрешить

## Сборка из исходников

Нужен JDK 17 и Android SDK:

```bash
export JAVA_HOME=/path/to/jdk-17
export ANDROID_HOME=/path/to/android-sdk
./gradlew :app:assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```
